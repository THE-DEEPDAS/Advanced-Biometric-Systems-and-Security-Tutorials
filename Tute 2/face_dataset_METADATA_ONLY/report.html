📋 Evaluation Metrics

For each dataset variant (REAL, GAUSSIAN, SALT-PEPPER):

  • FMR (False Match Rate): Probability of incorrectly accepting impostors
  • FNMR (False Non-Match Rate): Probability of rejecting genuine pairs
  • EER (Equal Error Rate): Point where FMR = FNMR
  • AUC (Area Under Curve): Overall discrimination ability
