📝 METADATA CONTENT
═══════════════════════════════════════════════════════════════════════════════

Each of 200 subject records contains:
  • subject_id: Unique identifier (S0001 to S0200)
  • subject_number: Numeric ID (1-200)
  • gender: M or F
  • ethnicity: Asian, Caucasian, African, or Hispanic
  • age_image1: Age at first capture (18-75 years)
  • age_image2: Age at second capture (1-5 years later)
  • age_gap_years: Years between images (guaranteed ≥ 1)
  • capture_date_1: ISO timestamp of first capture
  • capture_date_2: ISO timestamp of second capture
  • image1_real: Path to first REAL variant image
  • image2_real: Path to second REAL variant image
  • image1_gaussian: Path to first GAUSSIAN variant image
  • image2_gaussian: Path to second GAUSSIAN variant image
  • image1_salt_pepper: Path to first SALT-PEPPER variant image
  • image2_salt_pepper: Path to second SALT-PEPPER variant image

Total Metadata Records:   200
Metadata File Size:       112 KB
Format:                   JSON (UTF-8)
