TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Failed to download" or "Download interrupted"
────────────────────────────────────────────────────────
Solution:
  1. Try a different archive:
     - If downloading complete.tar.gz fails, try individual .zip files
     - Smaller files are more reliable
  2. Use a download manager (helpful for large files)
  3. Check your internet connection
  4. Try downloading at a different time

PROBLEM: "Cannot extract the file"
──────────────────────────────────
Solution:
  1. Ensure you have an archive tool installed:
     - Windows: Built-in or 7-Zip
     - Mac: Built-in or Keka
     - Linux: tar, unzip commands
  2. Download file again (may be corrupted)
  3. Try a different file format (.zip vs .tar.gz)

PROBLEM: "File is incomplete after extraction"
──────────────────────────────────────────────
Solution:
  1. Verify file size matches:
     - REAL.zip should be ~7 MB
     - GAUSSIAN.zip should be ~22 MB
     - SALT_PEPPER.zip should be ~22 MB
  2. Check available disk space (need ~100 MB)
  3. Download again if file size doesn't match

PROBLEM: "Cannot load metadata.json"
────────────────────────────────────
Solution:
  1. Ensure file exists: face_dataset/metadata.json
  2. Check file is not corrupted:
     python: import json; json.load(open('face_dataset/metadata.json'))
  3. Use correct file path (case-sensitive on Linux/Mac)

PROBLEM: "Missing images or incomplete dataset"
──────────────────────────────────────────────
Solution:
  1. Verify all 3 variants downloaded:
     - REAL/ (400 images)
     - GAUSSIAN/ (400 images)
     - SALT_PEPPER/ (400 images)
  2. Download missing variant(s) separately
  3. Ensure extraction was complete (no errors during extraction)
